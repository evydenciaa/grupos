# Preparar deploy e checagem de hospedagem compartilhada Plesk
Leia docs/PLESK.md. Confirme PHP CLI/web, extensão, Composer, DB, cron mínimo, storage, HTTPS e document root. Não usar processos permanentes. Não fazer deploy automático. Gere checklist de evidências e rollback; nunca registrar tokens.
